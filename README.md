# 🧠 Memory Game

A classic memory game built with HTML, CSS, and JavaScript. Test your memory skills by matching pairs of cards!

---

## 🚀 Getting Started

Follow these simple steps to get a copy of the project up and running on your local machine.

### Prerequisites

You don't need much! Just a modern web browser (like Chrome, Firefox, Safari, or Edge) to open the `index.html` file.

### Installation

This project doesn't require any complex installation process or dependencies.

1.  **Clone the repository:**
    Open your terminal or command prompt and run:

    ```bash
    git clone [https://github.com/LayzaK/memory-game.git](https://github.com/LayzaK/memory-game.git)
    ```

2.  **Navigate to the project directory:**

    ```bash
    cd memory-game
    ```

3.  **Open the game:**
    Simply open the `index.html` file in your preferred web browser. You can usually do this by double-clicking the file in your file explorer, or by dragging and dropping it into your browser window.

    ```bash
    # Example command (might vary based on your OS)
    # macOS:
    open index.html

    # Windows:
    start index.html

    # Linux (using xdg-open for general file opening):
    xdg-open index.html
    ```

    And that's it! The game should open in your browser, ready to play.

---

## 🎮 How to Play

Click on any two cards to flip them over. If they match, they'll stay face up. If they don't, they'll flip back down. Try to match all pairs in the shortest amount of time!
